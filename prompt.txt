Build a production-ready Automated Payment Recovery & Invoice Reminders SaaS based on README.md.:

1. Live Integrations: Real QuickBooks & Xero integration via .env.
2. Direct Payments: Email/SMS notifications with live Stripe links that pay directly to the user's account.
3. Instead of using link for changing password/forgotten password & for Sign Up use otp verification.
4. Use tricks for QuickBooks & Xero:
* Use Webhooks (Don't Poll): Instead of running a background loop that asks "Are there new invoices?" every 10 minutes, let QuickBooks and Xero ping your server only when an invoice is updated. This cuts API calls by ~90%.
* Fetch in Batches: Don't request invoices one by one. Use pagination and request up to 50–100 invoices in a single API call.  
* Smart Caching: Store invoice data in database and only fetch from QuickBooks/Xero when a webhook notifies of a change.
